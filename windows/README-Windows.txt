LogAtlas для Windows — анализатор журналов macOS, Windows и Linux
==================================================================

Запуск
  Дважды щёлкните LogAtlas.exe — откроется окно LogAtlas. Сервер работает внутри окна и
  завершается вместе с ним; если идёт разбор, LogAtlas спросит, точно ли закрыть.
  Меню значка в заголовке окна (или Alt+Пробел): «Открыть в браузере», «Папка данных»,
  «Журнал программы», «О LogAtlas».
  Окну нужен Microsoft Edge WebView2 Runtime (есть в Windows 11 и обновлённой Windows 10). Если его нет,
  LogAtlas откроется в браузере со значком в области уведомлений.

Журналы этого компьютера — кнопка «Этот компьютер…» на главной странице (попросит права администратора,
архив разберётся сам).

Где данные
  Переносная версия (рядом лежит portable.txt) хранит всё в папке data рядом с LogAtlas.exe —
  папку можно переносить на флешке. Установленная версия — в %LOCALAPPDATA%\LogAtlas.
  Удалите portable.txt, если хотите, чтобы данные хранились в профиле пользователя.

Настройки — settings.json в папке данных (создаётся при первом запуске):
  "port": 8484          порт панели (если занят — LogAtlas возьмёт следующий свободный)
  "host": "127.0.0.1"   127.0.0.1 — только этот компьютер; 0.0.0.0 — доступ из сети
  "workers": 0          число процессов разбора (0 — по числу ядер)

Служба Windows (панель работает без входа пользователя и открывается с других компьютеров)
  install-service.cmd   — установить и запустить службу (попросит права администратора);
                          правило брандмауэра пускает к порту 8484 только из локальной подсети
  uninstall-service.cmd — остановить и удалить службу
  Данные службы — %ProgramData%\LogAtlas, журналы службы — %ProgramData%\LogAtlas\logs.
  Когда служба работает, окно LogAtlas показывает её (LogAtlas.exe --app — своё окно со своим сервером).
  Не перемещайте папку LogAtlas после установки службы: служба запускается из неё.
  В LogAtlas нет входа по паролю — открывайте панель только в доверенной сети.

Сбор с других хостов по SSH
  Нужен встроенный клиент OpenSSH (Windows 10 1809 и новее; если его нет: Параметры → Приложения →
  Дополнительные компоненты → «Клиент OpenSSH»).

Попробовать без своих журналов: загрузите в панель архивы из папки demo.

Закрыть все запущенные копии из командной строки: LogAtlas.exe --quit
Журналы программы: logatlas.log и window.log в папке данных.

Исходный код и документация: https://github.com/ArsIS-02/logatlas
