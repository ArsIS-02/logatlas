# Обход блокировок антивирусами

LogAtlas использует PowerShell-скрипты для сбора журналов Windows. Некоторые антивирусы могут блокировать их, так как скрипты запускаются с правами администратора.

## Почему это происходит

- Скрипты запускаются от имени администратора (для чтения журнала Security)
- PowerShell-скрипты — популярный вектор атак, поэтому антивирусы проверяют их тщательно
- Windows SmartScreen может помечать неизменные executables как небезопасные

## Что делает LogAtlas безопасным

1. **Только чтение** — скрипты только читают журналы событий через `wevtutil`
2. **Никаких изменений в системе** — файлы не создаются вне временной папки
3. **Нет скачивания кода** — скрипты работают только с локальными файлами
4. **Открытый код** — весь код доступен на GitHub для проверки

## Как добавить исключение в Windows Defender

### Способ 1: Через настройки

1. Откройте **Безопасность Windows** → **Вирусы и угрозы**
2. **Управление защитой** → **Исключения**
3. **Добавить исключение** → **Папка**
4. Выберите папку `%LOCALAPPDATA%\LogAtlas`

### Способ 2: Через PowerShell (от администратора)

```powershell
Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\LogAtlas"
Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\LogAtlas\local"
```

## Как отключить SmartScreen (временно, при установке)

1. Скачайте установщик LogAtlas
2. Нажмите **Правая кнопка → Свойства**
3. Внизу поставьте галочку **Разблокировать**
4. Нажмите **Применить**
5. Запустите установку

Или через PowerShell:

```powershell
Unblock-File -Path "C:\Users\Имя\Downloads\LogAtlas-Setup.exe"
```

## Если скрипт всё равно блокируется

### Проверка карантина

1. **Безопасность Windows** → **Вирусы и угрозы** → **Журнал защиты**
2. Найдите записи о блокировках `collect-windows-headless.ps1`
3. Нажмите **Восстановить** или **Разрешить**

### Добавление исключения для PowerShell

```powershell
Add-MpPreference -ExclusionPath "C:\Program Files\LogAtlas"
Add-MpPreference -ExclusionProcess "powershell.exe"  # осторожно!
```

## Для корпоративных антивирусов

Если используется корпоративный антивирус (Kaspersky, ESET, Bitdefender и т.д.):

1. Обратитесь к администратору с запросом на добавление исключений
2. Укажите папку `%LOCALAPPDATA%\LogAtlas`
3. Укажите, что скрипты подписаны и доступны на GitHub

## Подпись кода (EV Certificate)

В будущих версиях LogAtlas будет подписан EV-сертификатом, что:
- Убирает предупреждения SmartScreen
- Уменьшает количество блокировок антивирусами
- Подтверждает авторство разработчика

Если у вас есть EV-сертификат, передайте его команде для подписи.

## Отчёт о ложном срабатывании

Если LogAtlas заблокирован антивирусом, который вы доверяете:

1. Сделайте скриншот сообщения об блокировке
2. Отправьте отчёт на GitHub Issues
3. Укажите название и версию антивируса

Это поможет улучшить совместимость в будущих версиях.
